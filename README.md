# AWS Data Engineering — Learning Journey

A structured documentation of my progress through the **AWS Skill Builder: Data Engineering on AWS** learning path. This repo serves as both a personal knowledge base and a portfolio of hands-on work.

---

## About This Learning Path

This is an official AWS learning plan covering the full spectrum of data engineering on AWS — from foundational concepts to building real data pipelines. It spans five courses (20h 20m total), with hands-on labs included in four of them.

## Topics Covered

- Data discovery and modern data architecture principles
- Building and governing data lakes on Amazon S3
- Data warehousing with Amazon Redshift
- Batch data pipelines with AWS Glue and Amazon EMR
- Real-time streaming with Amazon Kinesis and Amazon MSK
- Security, governance, monitoring, and cost optimization across all layers
